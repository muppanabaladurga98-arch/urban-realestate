# UrbanNest — Advanced Real Estate Website

A responsive, frontend-only real estate website built with plain HTML, CSS and JavaScript.

## Included
- Premium responsive design for desktop/tablet/mobile
- UrbanNest logo, dark/light logo and favicon
- Local SVG property and neighborhood artwork (no broken external image dependencies)
- Property cards with filtering by type, location and budget
- Save/favorite properties with browser localStorage
- Property detail modal and private-viewing CTA
- Saved-property view
- Mortgage/EMI calculator
- Dark mode
- Mobile navigation
- Contact/enquiry form UI
- Responsive neighborhood and service sections
- Accessible labels, semantic structure and keyboard Escape support

## Run
Open `index.html` in any modern browser. No build tools or server are required.

## Customize
- Edit property data in `script.js`.
- Change colors/spacing in `style.css` under `:root`.
- Replace artwork in `assets/images/` with your own JPG/WEBP images if desired.
- Replace the displayed phone number in `index.html` and `script.js` if your business number changes.

## Note
The contact form is frontend-only. To receive real enquiries, connect it to your preferred backend/form service. The phone CTA uses +91 80747 46443.
